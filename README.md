# Cartas Proyectivas
Aplicación compartida de cartas proyectivas. Siete barajas: COPE, Shame, Parcuve, Recursos, Autocuidado, Estados emocionales y Sistemas de protección. Respaldada por Supabase. La aplicación anterior `mesa-cope` permanece intacta.

Las imágenes deben copiarse desde el paquete a `public/decks/` preservando las carpetas.

**Prototipo:** validar permisos RLS, sincronización y privacidad antes de usar datos clínicos.
